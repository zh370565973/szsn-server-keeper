# 全量核对

2026-11-11。对照 [PRD.md](../PRD.md) 的需求编号和 AT-01 至 AT-20。用户同意先跳过麒麟现场和真实 CPU 压力，继续做本条；那些条目保持未完成，后续再验证。本文件不把编译或单测通过写成产品验收已全部结束。

状态只用三种：

- **开发侧完成**：开发机上已有测试或运行证据。
- **未完成**：还没有对应证据。目标环境项写明「目标环境待验收」。
- **已知限制**：已经实现的边界，不能当成该条已在目标环境通过。
